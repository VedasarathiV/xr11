xr11 2.0.0 — macOS application (Apple Silicon: M1/M2/M3/M4)
================================================================

INSTALL
  1. Open  xr11_2.0.0_aarch64.dmg
  2. Drag the xr11 icon into Applications
  3. Open xr11 from Applications (or Launchpad)

FIRST LAUNCH
  This build is signed locally (ad-hoc), not notarized by Apple. If macOS
  says it cannot verify the app, right-click the xr11 icon and choose Open,
  then confirm Open once. After that it opens normally.
  Requires macOS 11 or newer. Intel Macs need a separate x64 build.

WHAT IT DOES
  xr11 is a download manager for your Mac:
  - downloads files in up to 32 parallel connections and resumes after sleep,
    crashes or a closed lid without starting over
  - catches downloads and videos from Chrome, Edge, Brave, Vivaldi, Opera and
    Firefox through its browser extension (Settings > Browser integration)
  - saves video/audio from sites with yt-dlp, and opens .torrent / magnet links
  - organizes downloads into queues with speed limits and a scheduler
  - Hugging Face model search plus direct model-file links from other hubs,
    with model files grouped in the AI models category
  - custom completion sounds, including the built-in macOS Glass alert
  - keeps everything local: no account, no ads, no telemetry
